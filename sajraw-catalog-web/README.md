# Sajraw PDF Catalog Maker (PWA + Supabase)

1. Supabase: create a project, run `supabase-setup.sql` in SQL Editor.
2. Authentication > Users > Add user (your email + password). Authentication > Sign In / Providers > Email: turn OFF "Allow new users to sign up".
3. Project Settings > API: copy the Project URL and anon public key into `config.js`.
4. Upload this whole folder to a GitHub repo, enable Pages (Settings > Pages > Deploy from branch > main / root).
5. Open the https://<you>.github.io/<repo>/ link in Safari > Share > Add to Home Screen.
